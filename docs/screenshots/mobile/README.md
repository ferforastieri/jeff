# Mobile screenshots

The compact shell at **390 × 844 CSS px, 2× density**, in dark and light themes.
The same build also works at 360 px and 430 px; the layout is single-column below
900 px, the breakpoint where the app switches from the desktop workbench.

The navigation follows the Discord mobile shape: five labeled destinations in a
bottom bar, a channel list that pushes a full-screen chat, a profile bar above the
bar, sheets for details and dialogs, and a back chevron on every pushed screen.
The workbench uses the same shell with Trabalho, Jeff, Arquivos, Git and Mais.
